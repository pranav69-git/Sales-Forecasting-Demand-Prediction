# Sales Forecasting & Demand Prediction (Time Series + Dashboard)

## 📌 Project Overview
This project forecasts future retail sales using time-series forecasting and provides an interactive dashboard for business decision-making.

## ✅ Features
- Data preprocessing and monthly aggregation
- Exploratory Data Analysis (EDA)
- Forecasting using time-series model
- Model evaluation using MAE, RMSE, MAPE
- Dashboard-ready insights and forecast output

## 📂 Files Included
- `retail_sales_forecasting_dataset.csv` → Dataset
- `monthly_sales_forecast_output.csv` → Forecast output for dashboard
- `Project_2_Sales_Forecasting_Colab.ipynb` → Full notebook code
- `Project_2_Summary_Report.pdf` → Summary report
- `Project2_Dashboard.pbix` → Power BI dashboard file

## 🛠 Tools & Technologies
- Python (Pandas, NumPy, Matplotlib)
- Time Series Forecasting
- Power BI Dashboard
- Google Colab
